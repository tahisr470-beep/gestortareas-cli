
# Gestor de Tareas CLI

Aplicacion de consola desarrollada en Python para administrar tareas.

## Requisitos previos

- Python 3.8 o superior.
- Git instalado.

## Funcionalidades

- Agregar tareas.
- Listar tareas.
- Completar tareas.
- Eliminar tareas.

## Instrucciones de uso

Ejecutar el programa con:

python app.py
